Полная и актуальная версия RPG-мода для Killing Floor 1. Это проект уже закрытого сервера **[Dead Zone] RPG Mod [WSB]**. Репозиторий содержит всю необходимую сборку сервера вместе с исходным кодом для изучения или запуска.

## ⚠️ Важная информация

*   **Проект закрыт.** Данный репозиторий создан для архивации и сохранения полной рабочей версии мода.
*   **Исходный код включён.** Вы вправе использовать его в своих интересах.
*   **Для опытных пользователей.** Настройка и запуск требуют базового понимания работы серверов Killing Floor.
